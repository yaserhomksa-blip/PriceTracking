# Supermarket Price Tracker

Checks prices at Danube, Tamimi, Panda, Carrefour, Lulu (and lists Ninja, which is app-only) every morning, and shows them on one page.

- **Page:** https://yaserhomksa-blip.github.io/PriceTracking/
- **Add an item:** use the box at the top of the page.
- **Items list:** `items.json` · **Stores:** `stores.json` · **Latest prices:** `data/prices.json`
